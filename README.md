🤖 Automação de E-mails com IA usando n8n

📌 Sobre o projeto

Automação criada no **n8n** para receber e-mails, analisar as mensagens com Inteligência Artificial e gerar respostas automáticas de forma organizada e profissional.

⚙️ Tecnologias utilizadas

* n8n
* Gmail
* Inteligência Artificial
* API de IA

🔄 Funcionamento

1. Recebe um novo e-mail.
2. Analisa o conteúdo da mensagem.
3. A IA cria uma resposta personalizada.
4. A resposta é enviada automaticamente.

📸 Demonstração

Workflow desenvolvido e testado no n8n com execução concluída com sucesso.

📂 Arquivo

workflow.json → Arquivo da automação para importar no n8n.
